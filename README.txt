EMOTIONS-TAGEBUCH – GITHUB PAGES

1. GitHub: New repository → Name z.B. emotionstagebuch → Public → Create repository.
2. Unter Add file → Upload files alle Dateien aus diesem Ordner (nicht die ZIP-Datei) ins Hauptverzeichnis hochladen und Commit changes wählen.
3. Settings → Pages → Build and deployment → Deploy from a branch → Branch main / (root) → Save.
4. Einige Minuten warten. URL: https://DEIN-BENUTZERNAME.github.io/emotionstagebuch/
5. iPhone: URL in Safari öffnen → Teilen → Zum Home-Bildschirm.
   Android: URL in Chrome öffnen → Menü → App installieren / Zum Startbildschirm.
6. Einmal online laden, danach offline nutzbar.

DATENSCHUTZ
GitHub erhält nur App-Dateien. Namen, Tagebucheinträge und Auswertungen werden lokal im Browser-/App-Speicher gespeichert. Keine externen Ressourcen, kein Tracking. GitHub kann normale Zugriffslogs für den Abruf der App-Dateien führen.
WICHTIG: Vor dem Umstieg auf die GitHub-Version in der alten HTML-App JSON exportieren; dann in der GitHub-Version JSON importieren. Browser-Speicher der lokalen Datei wird NICHT automatisch übernommen. Daten auf verschiedenen Geräten werden NICHT synchronisiert. JSON-Backups sicher aufbewahren.
Die App selbst ist öffentlich aufrufbar. Keine persönlichen Daten ins Repository hochladen!
